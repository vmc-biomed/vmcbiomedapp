How to install

Pick your device. It only needs to be done once.

Android (Chrome)
  1. Open the link above in Chrome
  2. Tap the ⋮ menu, top right
  3. Tap Install app (or Add to Home screen)
  4. Tap Install to confirm
Icon appears on your home screen, opens full-screen like any app.
iPhone (Safari)
  1. Open the link above in Safari (must be Safari, not Chrome)
  2. Tap the Share icon (square with an arrow ↑)
  3. Scroll down, tap Add to Home Screen
  4. Tap Add, top right
On iPhone, notifications need this step first — a browser tab alone can't send them.
Computer (Chrome/Edge)
  1. Open the link above
  2. Click the install icon in the address bar (⊕ or a small monitor)
  3. Click Install
No icon? Use the ⋮ menu → Install VMC Biomed…
